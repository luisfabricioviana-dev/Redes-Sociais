# Agente de Redes Sociais

Repositório canônico para estratégia editorial, pauta, pesquisa de oportunidade, packaging, distribuição, performance, publicação e aprendizado pós-publicação do ecossistema de redes sociais.

## Escopo

Este repositório concentra mecanismos e memória reutilizável de:
- trend research e topic selection;
- research editorial e evidence review;
- angle, hook e packaging;
- adequação narrativa por plataforma;
- metadata, títulos, legendas e publicação;
- diagnóstico de performance e catálogo;
- regressões de tutoriais/casos;
- aprendizados cross-channel que sobrevivam aos gates de generalização.

A execução audiovisual detalhada permanece no repositório `agente-youtube` / Agente Audiovisual quando o assunto for produção, render, geo motion, áudio, montagem, QA multimodal e runtime audiovisual.

## Governança

- `NEW INPUT ≠ NEW RULE`
- `ONE CASE ≠ NEW RULE`
- `SHARED MECHANISM ≠ SHARED DOMAIN MEMORY`
- `CORE SHARED / CHANNEL IDENTITY ISOLATED`
- `ARCHITECTURE-VALIDATED ≠ CODE-RUNTIME-VALIDATED`
- `PERFORMANCE EVIDENCE > ANECDOTAL CONFIDENCE`

## Estrutura

- `regressions/` — auditorias e regressões de tutoriais, casos e referências.
- `learning/` — mecanismos promovidos/candidatos e sínteses de aprendizado.
- `profiles/` — memória e regras específicas de canais/perfis.
- `contracts/` — contratos operacionais quando houver formalização executável.
- `docs/` — documentação de arquitetura, decisões e governança.

## Política de promoção

Um aprendizado só deve avançar de caso para regra quando passar por:

`SOURCE → REGRESSION → GENERALIZABILITY CHECK → PROFILE-ISOLATION CHECK → CANDIDATE → TEST/VALIDATION → PROMOTION`

Quando houver implementação executável, aplicar também:

`CONTRACT → RED TEST → MINIMAL IMPLEMENTATION → REGRESSION → CI → REVIEW → MERGE`.
