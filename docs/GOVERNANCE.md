# Governance

## Core rules
- `NEW INPUT ≠ NEW RULE`
- `ONE CASE ≠ NEW RULE`
- `SHARED MECHANISM ≠ SHARED DOMAIN MEMORY`
- `CORE SHARED / CHANNEL IDENTITY ISOLATED`
- `ARCHITECTURE-VALIDATED ≠ CODE-RUNTIME-VALIDATED`

## Storage rule
- `regressions/`: source-specific audits and case studies.
- `learning/`: reusable mechanisms after abstraction.
- `profiles/`: channel-specific knowledge.
- `contracts/`: executable or formalized operational contracts.
- `docs/`: architecture and governance.

## Promotion rule
`SOURCE → REGRESSION → GENERALIZABILITY → PROFILE ISOLATION → CANDIDATE → VALIDATION → PROMOTION`
