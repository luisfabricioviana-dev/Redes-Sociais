# Learning

Armazena mecanismos generalizáveis extraídos de regressões, desempenho, experimentos e resultados.

## Estados
- `DRAFT`
- `CANDIDATE`
- `VALIDATED`
- `CANON`

## Regra
Um caso isolado não cria regra. Primeiro abstrair o mecanismo, testar generalização e verificar contaminação entre perfis.

`LOCAL OBSERVATION → REUSABLE MECHANISM → VALIDATION → PROMOTION`
